This repository keeps license information modular so that each component can
carry its own legal terms while still maintaining a clear project-level license.

## Module Licenses

## Assets and Third-Party Components

## Notes

- If you add a new module that requires a separate license, place the license
  file alongside the module and document it here.
- Third-party code retains its original licensing terms. Always confirm
  compatibility before redistributing.
